# Chord Orchestrator v2 (Python Port) --- Completed on 02/17/2026

## Description: For the natural progression of the original C program, this new, 2.0 version was ported over to Python. The main reasons to port this program over to a higher-level language was not only to make the user's input responsive to sound (Through the MIDI library 'midiutil'), but to build the foundation for an AI learning model, where Markov Chains in the form of "Reference songs" will be used to teach the AI to play music based on certain motifs. This early rendition of the AI learning model enacts a single event in the form of creating a MIDI file based on the user's input. The terminal prompts the user for a keynote using a note from the chromatic scale, which sets the "octave" or starting point from which their chord is then generated. Once the keynote is entered, the user is subsequently prompted for a chord type, which in this case, lets them choose between the following chords: Major, Minor, Power, Dominant 7th, and Major 7th. Once inputs are complete, A MIDI file is generated with the chord of the user's choice that can be read into a DAW or MIDI player (e.g. VLC) where the user can hear their generated chord.

## Design Decisions: Instead of an array, as the previous version used in C to map the notes, this Python port uses dictionaries for both the 'NOTE_MAP' and 'CHORD_MAP', in order to store the information in a more readable format that also increases the efficacy of indexing both the note itself and the intervals used to make up the chord (As indicated by the use of '.get()' in the helper function). In the 'create_midi_chord' helper function, the 'root_note' and 'intervals' variables use the sentinel value of 'None' as their default, in the case that no note or chord type exists. This way, the security check will then fail and it will flag an error that the 'user_note' or 'user_chord_type' were not recognized. This is where 'midiutil' was added as a core dependency, as the final product needed to be a single MIDI file that actually played the sound of the chord notes. This was where by their documentation, I initialized the "Note Profile", which was essentially the musical data that needed to be applied to any given note. This included the following: The MIDI track (The "preset" of musical data), Channel (Route to an instrument type in the MIDI player), Time (The offset, or the starting point in beats), Duration (Length of time between offset and track completion in beats), Tempo (Pace of song in Beats Per Minute/BPM), and Volume. Once the "Note Profile" variables are declared, the 'midiutil'-specific function 'MIDIFile' is used to declare a single MIDI object within the program, allowing the program to later write the notes, and their respective profiles to a MIDI file. Other track-wide functions from 'midiutil' are used in the form of '.addTrackName()' and '.addTempo()' to add track-level data such as track length and tempo. Finally, the system loops through the existing notes in a MIDI object (So 'user_note' -> 'user_chord_type' -> note[interval]) and applies the musical data generated by the Note "Profile" to each of them. Once complete, the program writes the fully mapped chord data to the MIDI file, named after the user's original input before returning a successful outcome. There is also an 'exit' option in the initial interface so the user can exit the program without needing to input a note and chord or force quitting the program.

## Other Details: Security checks were added for the keynote ('root_note') and chord type ('intervals') so that any user input that wasn't found in either the 'NOTE_MAP' or 'CHORD_MAP' would return an error. Another check was added during the file writing process, to account for any system-side Input/Output errors regarding inability to write the data to a MIDI file. Finally, a simple check was added in the main interface function where if the 'create_midi_chord' function failed to run, it would return an error message prompting the user to try again with valid inputs.

## Dependencies: sys, midiutil, MIDIFILE
